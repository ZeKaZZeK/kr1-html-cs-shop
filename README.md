# KeyForge — магазин механических клавиатур

## Контрольная работа №1
Тема: «HTML и CSS: разработка многостраничного сайта».
Многостраничный HTML/CSS-сайт интернет-магазина без фреймворков.

**Студент:** Ермаков Арсений Анатольевич, ЭФБО-09-25

## Ссылка на опубликованный проект
GitHub Pages: https://zekazzek.github.io/kr1-html-cs-shop/
## Структура проекта
```
kr1-html-css-shop/
├── index.html      главная: hero, преимущества, популярные товары, контакты
├── catalog.html    каталог, sticky-блок фильтров
├── product.html    карточка товара, таблица характеристик, модальное окно
├── order.html      форма заявки
├── contacts.html   контактная информация
├── css/style.css   все стили
├── js/main.js      открытие/закрытие модального окна
└── images/
```

## Технологии
HTML5 (семантика), CSS3 (переменные, Flexbox, Grid, position), БЭМ, минимальный JS для модального окна.

## Как посмотреть
Откройте `index.html` в браузере или перейдите по ссылке GitHub Pages.
