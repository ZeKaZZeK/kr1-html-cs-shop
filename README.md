## Технологии
HTML5 (семантика), CSS3 (переменные, Flexbox, Grid, position), БЭМ, минимальный JS для модального окна.

## Как посмотреть
Откройте `index.html` в браузере или перейдите по ссылке GitHub Pages.

## Публикация
Settings → Pages → Deploy from a branch → `main` / `(root)`.

## Что реализовано
- 5 страниц с единым меню, якорями (`#advantages`, `#popular`, `#contacts`), уникальными title и description.
- Карточки товаров (`article`) с бейджами Хит / Скидка / Новинка (`position: absolute`).
- Таблица с `caption`, `thead`, `tbody`, `th`, `td`.
- Форма: `label`/`for`/`id`, `name`, `required`, `type="email"`, согласие.
- CSS: `:root`-переменные, `:hover`, `:focus-visible`, `:disabled`, Grid каталога и страницы с фильтрами, Flex в меню и кнопках.
- Позиционирование: `sticky` (шапка, фильтры), `fixed` (кнопка «Наверх», модальное окно), `z-index`.

## Самостоятельные доработки
- Собственная визуальная концепция (клавиатурный паттерн вместо фото).
- Модификаторы карточек `--hit`, `--sale`, `--new`; зачёркнутая старая цена.
- Фильтры каталога, адаптивность под узкие экраны, закрытие модалки по Esc.
- Подсветка невалидных полей (`:user-invalid`), `aria`-атрибуты.
